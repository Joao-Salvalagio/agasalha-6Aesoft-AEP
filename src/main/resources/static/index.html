Agasalha

API do mural de doacao de agasalhos — ODS 1

Este endereco serve a API. O mural fica em http://localhost:5173, servido pelo Vite a partir de apps/web.

  • /docs — documentacao interativa (Swagger UI)
  • /v3/api-docs — contrato OpenAPI em JSON
  • /api/itens — recurso de itens
  • /actuator/health — saude da aplicacao

Como subir o mural: cd apps/web && npm ci && npm run dev. Passo a passo em docs/setup.md.
