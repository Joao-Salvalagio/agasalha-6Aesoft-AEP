# Glossário

Termos do domínio do Agasalha, em português.

| Termo | Significado |
|---|---|
| **agasalho / item** | peça de vestuário ou abrigo térmico doada (casaco, blusa, calça, cobertor, meia, outro) |
| **doador** | pessoa que oferece um ou mais agasalhos; é cadastrado e escolhido ao registrar uma doação (Entrega 2) |
| **doação** | ato de doar agasalhos, associando um doador às peças doadas; o abrigo é opcional e a peça recebe o destino quando é enviada ao abrigo (Entrega 2) |
| **abrigo** | instituição que recebe agasalhos e tem demandas específicas (Entrega 2) |
| **demanda** | necessidade declarada por um abrigo: tipo de peça, tamanho, gênero e quantidade (Entrega 2) |
| **estoque** | quantidade de itens que um abrigo já acomoda |
| **capacidade de estoque** | limite máximo de itens que um abrigo consegue acomodar |
| **déficit** | `quantidadeNecessaria - quantidadeAtendida` de uma demanda |
| **match** | sugestão de abrigo e demanda para uma peça: mesmo tipo e tamanho, gênero compatível, abrigo com espaço e demanda em aberto, priorizando o maior déficit (Entrega 2) |
| **enviar ao abrigo** | aplicar o match: a peça ganha o abrigo, entra no estoque dele, abate a demanda e fica reservada (Entrega 2) |
| **peça avulsa** | item cadastrado sem doação, com `nomeDoador` e `contatoDoador` no próprio documento (Entrega 1) |
| **mural** | tela pública que lista os itens disponíveis |
| **reserva** | marcação de um item disponível para uma entrega futura; só vale para peça que já tem abrigo e acontece ao enviar a peça ao abrigo |
| **entrega** | conclusão do ciclo: o item saiu para quem precisava; só vale para peça reservada, que já tem abrigo |
